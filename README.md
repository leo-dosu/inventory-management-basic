## Module: Stock Audit

### Overview
This repository contains the Stock Audit module. Stock Audit is the process of verifying physical stock against system records to ensure accuracy and prevent loss.

### Objectives
- To ensure physical stock matches system stock
- To detect damaged, expired, or missing items
- To generate discrepancy reports for accountability
