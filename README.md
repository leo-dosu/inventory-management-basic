# POS and Vendor Relations — Features (Your Name)

## 1. Vendor Price Comparison and Quote Requests
Allows the system to compare prices offered by different vendors for the same products and request quotations from vendors. This helps the business identify better purchasing options and manage vendor costs efficiently.

## 2. Returns to Vendor (RTV) and Credit Notes
Allows the business to record products returned to vendors due to defects, wrong items, or other issues, while also tracking the credit notes issued by vendors. This ensures vendor returns and related adjustments are properly documented.
