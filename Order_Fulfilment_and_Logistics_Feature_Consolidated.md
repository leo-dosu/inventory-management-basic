# Order Fulfilment and Logistics - 20 Features - Group 5

1. Order Tracking - Real-time order status tracking.
2. Delivery Scheduling - Customer chooses delivery date/time.
3. Inventory Check - Check stock before confirming order.
4. Shipping Cost Calculation - Auto calculate shipping fee.
5. Order Cancellation - Cancel before shipping.
6. Return and Refund Request - Request return for damaged items.
7. Warehouse Assignment - Auto assign to nearest warehouse.
8. Logistics Partner Assignment - Assign to DHL, GIG, etc.
9. Proof of Delivery - Upload signature/photo.
10. Delivery Route Optimization - Optimized route for riders.
11. Fulfilment Status Update - Staff updates fulfilment stage.
12. Customer Notification - SMS/Email alerts on status.
13. Bulk Order Processing - Process many orders at once.
14. Invoice Generation - Generate invoice after confirmation.
15. Packing List Generation - Packing list for warehouse.
16. Low Stock Alert - Alert when stock low from fulfilment.
17. Failed Delivery Handling - Reschedule failed deliveries.
18. Delivery Feedback Rating - Customer rates delivery.
19. Order History View - View past orders history.
20. Logistics Dashboard - Dashboard for delivery performance.
